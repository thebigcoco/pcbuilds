# PCPartPicker PC Build 統計報告

以 PCPartPicker Completed Builds 資料產生的互動式統計報告（2025/4 – 2026/6，共 9,334 台 Build）。

## 報告

- [全期間 2025/4 – 2026/6](https://thebigcoco.github.io/pcbuilds/PCPartPicker_Report_202504-202606.html)
- [2025 年（4–12 月）](https://thebigcoco.github.io/pcbuilds/PCPartPicker_Report_202504-202512.html)
- [2026 年（1–6 月）](https://thebigcoco.github.io/pcbuilds/PCPartPicker_Report_202601-202606.html)

報告內含各類別品牌統計、重點細項統計（CPU／主機板／記憶體／儲存／電源／顯示卡等）、四大板廠 Product Series 統計、同品牌多零組件組合分析與趨勢圖表；三份報告可透過標題列的期間切換互相跳轉。
